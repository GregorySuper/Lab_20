# Сайт ССК ЮФУ «Южная стая»

Сайт спортивного студенческого клуба ЮФУ. Одностраничное приложение (SPA)
на React с маршрутизацией. Проект создан на Create React App.

## Как запустить

```bash
cd site
npm install      # установить зависимости (один раз)
npm start        # запустить сайт, откроется http://localhost:3000
```

Сборка готовой версии: `npm run build` (результат появится в папке `build`).

## Используемые технологии

- **React** — библиотека для интерфейса.
- **react-router-dom** — маршрутизация между страницами без перезагрузки.
- **Create React App** (`react-scripts`) — сборка и dev-сервер.
- Обычный CSS (без сторонних UI-библиотек).

## Структура проекта

```
src/
  index.js              — точка входа, подключает BrowserRouter
  App.js                — макет: Header + страницы (Routes) + Footer
  index.css             — фирменные шрифты, цвета и общие стили
  fonts/                — фирменные шрифты Carlo Melow
  components/
    Header.jsx / .css   — шапка с меню и кнопкой-бургером
    Footer.jsx / .css   — подвал с контактами
  pages/
    News.jsx            — Новости (стартовая страница)
    Team.jsx            — Команда
    Calendar.jsx        — Календарь мероприятий (свой календарь)
    Events.jsx          — Мероприятия (с фильтром по виду спорта)
    Contacts.jsx        — Контакты + форма «Подать заявку»
    NotFound.jsx        — Страница 404
    pages.css           — стили всех страниц
  data/
    news.js             — список новостей
    team.js             — состав команды
    events.js           — список мероприятий
public/
  index.html            — HTML-шаблон
  img/                  — логотипы и элементы из брендбука
```

## Как добавить контент (для администратора)

- **Новость** — добавить объект в начало массива в `src/data/news.js`.
- **Участника команды** — добавить объект в `src/data/team.js`.
- **Мероприятие** — добавить объект в `src/data/events.js`
  (дата в формате `ГГГГ-ММ-ДД` — она автоматически попадёт и в календарь).

## Фирменные цвета (из брендбука)

- Белый `#FFFFFF` — фон

- Яркий синий `#257ABB` — акцент

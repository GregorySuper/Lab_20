# Сайт ССК ЮФУ «Южная стая»

## Концепция
Тема сайта — студенческий спортивный клуб «Южная стая» Южного федерального университета. Сайт-визитка, содержащая информацию о клубе, тренерском составе, новостях, календаре мероприятий и контактах.

## Команда
Команда состоит из двух человек — Яценко Г.А. и Беляевский Н.А. Яценко Г.А. выполняет следующие роли: Менеджер проекта, Архитектор, Дизайнер интерфейса (UI-дизайнер), Дизайнер-эргономист (UX-дизайнер), Верстальщик, Программист, Тестировщик. Беляевский Н.А. выполняет следующие роли: Системный аналитик, DevOps инженер, Администратор, Технический писатель.
